## 🌱 Projects Showcased

### 1. [Mobile Field Reporting Workflow](https://github.com/YamkelaDev/Mobile-field-reporting-workflow)
A mobile-first filing and showcase system for agricultural field data. Bridges on-ground observation with digital record-keeping — includes admin panel, upload system and public reporting showcase.

### 2. [Agrotechnical Logistics Assister](https://github.com/YamkelaDev/agrotechnical-logistics-assister)
Systematic tool for agricultural logistics and supply correlation — tracking farm outputs and coordinating field-to-market distribution workflows.

### 3. Chili Product Landing Pages
Fire-themed, conversion-focused marketing pages and animated posters for **Red Cayenne Chili Mash** and other agri-products.

### 4. Farm Brand Identities, Logos & App
Visual identities and an app built for agricultural businesses across South Africa — covering print and digital brand presence end-to-end.

## 🛠 Built With

- **React 19 + TypeScript** — component-driven UI
- **Three.js** via **@react-three/fiber** + **@react-three/drei** — the immersive hero PC that follows your cursor, the rotating globe, and the 3D monitor project showcase
- **Tailwind CSS** — utility-first styling
- **Vite** — build tooling
- **Google Fonts** — Space Grotesk + Playfair Display
- **GitHub Actions + GitHub Pages** — automatic build & deploy on every push to `main`
